# Mediatsiya AI

AI yordamida onlayn mediatsiya platformasi: nizoni sudga bormasdan, mediator yordamida hal qilish.
Adliya vazirligi xakatoni uchun loyiha.

- Frontend: Next.js (Netlify)
- Backend: Django + DRF (AWS EC2, Frankfurt)
